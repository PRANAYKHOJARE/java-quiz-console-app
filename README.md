# Java Quiz Console Application

A simple Java console-based quiz application built using Object-Oriented Programming principles.

## Features
- Multiple choice questions
- User input using Scanner
- Score calculation
- Clean modular code structure

## Technologies Used
- Java
- OOP Concepts
- Arrays
- Scanner Class

## How to Run

1. Compile the program
   javac *.java

2. Run the program
   java Main

   java-quiz-console-app
